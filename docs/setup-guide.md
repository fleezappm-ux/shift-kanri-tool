# 導入手順書（はじめての店舗向け）

所要時間のめやす：15分前後（目標。実機で計測して更新します）。パソコンで、**Googleアカウント1つ**だけで進めます。
**1つ終わるごとに ☐ にチェック**を入れてください。かならず「自分の店専用」のスプレッドシートを使います（別の店のものを共用しません）。

> **先に読んでください**
> - ブラウザの自動翻訳がONだと、ボタン名が手順書と合わなくなります。迷ったら翻訳をOFFにしてください。
> - 接続キー・パスワードは、ほかの人に見える場所（掲示板・チャット）に貼らないでください。
> - 店のデータは、あなたのGoogleドライブの**スプレッドシート**に保存されます（「シフト」「休み希望」「設定」の3枚のシート）。

## 全体の流れ

1. 配布元のスプレッドシートを**コピー**する（約2分）
2. 「初期設定」の質問に答える（約5分）
3. ウェブアプリとして公開して、URLをもらう（約5分）
4. 画面を開いて、URLを1回だけ入れる（約2分）
5. 従業員に配る

## 1. スプレッドシートをコピーする

- ☐ 1-1. 配布元から送られた**スプレッドシートのリンク**を開き、「ファイル」→「コピーを作成」を押す（コピー先は自分のドライブ）。
  シートと一緒に、動かすためのプログラムもコピーされます。
- ☐ 1-2. コピーしたスプレッドシートを開く。上のメニューに「**シフトツール**」が出るまで、数秒待つ（出なければ、ページを読み込み直す）

## 2. 初期設定（質問に答えるだけ）

- ☐ 2-1. メニュー「シフトツール」→「① 初期設定を始める」を押す。**初回だけ**権限の確認が出ます。**自分のアカウント**を選び、「詳細」→「（プロジェクト名）に移動」→「許可」の順に進めます（「このアプリは確認されていません」と出ますが、自分のコピーなので大丈夫です）。許可したら、もう一度メニューから押してください。
- ☐ 2-2. 6つの質問に答える：管理者のログインID／管理者のパスワード／従業員共通のログインID／従業員共通のパスワード／あなたの名前／店舗名
- ☐ 2-3. 最後に出る**接続キー**を控える（あとからメニュー「接続キーを表示する」でも見られます）
- ☐ 2-4. メニュー「設定の状態を確認する」で `【すべてOK】` と出ればOK

## 3. ウェブアプリとして公開する

- ☐ 3-1. メニュー「拡張機能」→「Apps Script」を開く
- ☐ 3-2. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイ
- ☐ 3-3. 表示される**ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーして控える

## 4. 画面を開いて、つなぐ

- ☐ 4-1. 配布元から送られた**画面のリンク**を開く。はじめて開くと「お店につなぐ」と出るので、3-3 のURLを貼って「つなぐ」を押す
  （配布元が `…/?gas=URL` の形のリンクを作ってくれた場合は、そのリンクを開くだけでつながります）
- ☐ 4-2. 管理者ID・パスワードでログインし、自分の名前を選ぶ。**はじめてのときは、自分のPIN（4〜6桁の数字）を決めます**（2回入れます。忘れないよう控えてください）
- ☐ 4-3. 画面上の黄色い案内から、**接続キー**（2-3）を入れて「保存して接続を確認」。✓が出ればOK（1端末につき1回だけ）
- ☐ 4-4. 設定 → 従業員マスタで、自分の名前を直し、従業員を登録する（人数の上限はありません）
- ☐ 4-5. 設定 → 店舗マスタで、集計期間（月の区切り）を決める
- ☐ 4-5b. （任意）設定 → 店舗マスタの下の方で、曜日ごとの営業時間と「営業時間のあいだ、いつも誰かいてほしい役職」を決める。決めると、その役職の人が抜ける時間帯がある日を、全体シフトで「⚠」と知らせます
- ☐ 4-6. 設定 → シフトマスタ → 勤務時間設定で、早番・遅番などを登録する
- ☐ 4-6b. （任意）設定 → シフトマスタ → 人数・連勤のチェックで、曜日ごとの最低人数や連勤の上限を決める。決めた基準に合わない日は、全体シフトで「⚠」と出ます。決めなければチェックしません
- ☐ 4-6c. （任意）シフト作成画面の「質問に答えてシフト案を作る」で、最低人数・連勤・一人ひとりの働き方（週の日数・毎週決まった休み・早番か遅番か）に答えると、案を作ります。案は「この案を使う」を押すまで反映されず、あとから元に戻せます
- ☐ 4-7. 試しにシフトを1日入れて、「保存済み」になり、スプレッドシートの「シフト」シートに行が増えることを確認する

## 5. 従業員に配る

- ☐ 5-1. 画面のリンク・お店のウェブアプリのURL・**従業員共通のID・パスワード**を伝える（`…/?gas=URL` の形のリンクなら、URLの入力は不要です）（LINEなどで。掲示板やGitHubには書かない）。あわせて「**最初のログインで、自分のPIN（4〜6桁の数字）を決めてください**」と伝える。PINは本人だけが知る番号で、ほかの従業員のマイページや有給を見られなくするためのものです
- ☐ 5-1b. 従業員がPINを忘れたら、設定 → 従業員マスタ →「PIN（暗証番号）のリセット」で、その人の「PINをリセット」を押す。本人は次のログインで決め直します
- ☐ 5-2. スマホは「ホーム画面に追加」を案内する（ホームのシフトのアイコンに方法が出ます）
- ☐ 5-3. 使い方は、アプリ内の「使い方」を見てもらう

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| メニュー「シフトツール」が出ない | ページを読み込み直す。コピーしたスプレッドシート（元のではなく）を開いているか確認 |
| 「設定の状態を確認する」に NG が出る | その行の指示どおりに直す |
| ログインできない | 初期設定で決めたID・パスワードの綴り。「PINが違います」なら、本人に確認し、忘れていれば管理者がPINをリセット（設定 → 従業員マスタ） |
| 画面が「通信できません」 | 入れたURLが正しいか。3-2 のアクセスが「全員」か |
| プログラムを直したのに反映されない | デプロイを「新バージョン」で更新したか（URLは変わりません） |
| 画面が古い | 画面の更新ボタンを押す |

## 付録：エラー記録

画面でエラーが起きると、自動で記録されます。管理者は 設定 → その他設定 の「エラー記録」で見られます。
